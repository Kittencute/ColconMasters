Simple ROS/Gazebo sensor meshes
Units: meters, so use scale 1 1 1.

Files:
- oakd_s2.stl: simplified OAK-D S2 body with 3 front lenses
- 3dm_gv7_ahrs.stl: simplified 36.2 x 36.6 x 10.2 mm IMU body with connector bump
- livox_mid360.stl: simplified 65 x 65 x ~60 mm MID-360-style body with rounded top

These are approximate visual meshes, not manufacturer CAD.
Use simple primitives for collision geometry.
